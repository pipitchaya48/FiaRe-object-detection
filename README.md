### Basic Information
This directory is a clone of the training pipeline for smoke and cars object detection model for a firefighther camera-aided system.
Below are some important notes on navigating important files:

- **Managing Files and Training**: main functions can be found in _Hackmit/Hackmit/Export_modules/detectAndLabel.py_
- **Trained Model**: The weight of trained models are listed in _Hackmit/Hackmit/Export_modules/models_
- **Visualize on Video**: The file _/Img_Recognition/car_detection.py_ provides a function for visualizing detection of cars in the uploaded video
